# VLA-4D 精读笔记

> Zhou, Ma, Lee, *VLA-4D: Embedding 4D Awareness into Vision-Language-Action Models for SpatioTemporally Coherent Robotic Manipulation*, arXiv 2511.17199v1 (2025-11-21)
> NUS + 华中科技大学。**无官方代码，无数据集释出。**

## 1. 核心主张

现有方法把 **3D 位置**嵌入视觉表征来提升动作的空间精度，但**管不住时间维度**，表现为空转停顿（idle pauses）和抖动（jitter）。
VLA-4D 主张：**必须在"视觉表征"和"动作表征"两端同时注入时空信息**。

论文自己划的三代范式（Fig. 1）：
- (a) 2D VLA：视觉+语言 → LLM → 动作，时空都不连续
- (b) 3D VLA：嵌 3D 位置，空间精度和平滑度改善，**但缺时间连贯性**
- (c) 4D VLA（本文）：3D 位置 + 1D 时间同时进视觉表征，**动作表征也扩到时空域**

## 2. 架构

```
第三人称视频 ┐                    ┌─ 视觉编码器 (Qwen2.5-VL 的 ViT) ─> f_v ─┐
             ├─>                  │                                        ├─> Cross-Attn 融合 ─> f_v^4D ─┐
腕部视频     ┘                    └─ 几何编码器 (VGGT) ─> 位姿P/深度D ─> p_3D ─┐                            │
                                                                    1D时间 t ─┴─> STE(Fourier) ─> f_4D ─┘   │
                                                                                                            ↓
本体感知状态 ──> Projector(MLP) ──> τ_p ──┐                                              Projector(MLP) ─> τ_v^4D
任务指令 ──> Text Tokenize ──> τ_l ───────┴──────────> 预训练 LLM ──> Action Head(MLP) ──> [Δx, Δθ, Grip, Δt]
```

### 2.1 4D-Aware Visual Representation

**Step 1 — 取 3D 位置**：用 **VGGT** 作几何编码器，提取时刻 t 的相机位姿 P 和深度 D，结合内参 K 把 2D 像素反投影到世界/机器人坐标系：

```
p_3D = P⁻¹ (D · K⁻¹ · p_2D)          … 式(2)
```

**Step 2 — 时空嵌入 STE**：Fourier 编码把位置和时间戳转成可学习模式，再经线性层映射成 4D 表征：

```
ψ(x) = 1/√d · [cos(x·Wrᵀ) ‖ sin(x·Wrᵀ)]
f_4D = w_p · [ψ(p_3D) ‖ ψ(t)]        … 式(3)
```
（Wr 是 Fourier 特征的可学习参数，d 是维度）

**Step 3 — Cross-Attention 融合**：先用 MLP 把 f_4D 对齐到视觉特征维度 `f̂_4D = MLP(f_4D)`，然后 **query 来自视觉特征，key/value 来自 4D 嵌入**，残差相加：

```
q = w_q·f_v,  k = w_k·f̂_4D,  v = w_v·f̂_4D
f_v^4D = f_v + softmax(q·kᵀ/√d)·v     … 式(4)
```

> 注意方向：是**把 4D 几何信息注入视觉特征**，不是反过来。残差结构保证不破坏原视觉语义。

### 2.2 SpatioTemporal Action Representation

传统空间动作：`X = [Δx, Δθ, Grip]`（平移 / 旋转 / 夹爪开合）
本文扩展为：**`A = [Δx, Δθ, Grip, Δt]`**

其中 `T = Δt` 是 **step 级的时间控制变量**，论文说它由三者共同决定：
- 场景内容（对应 VLA 的 vision）
- 操作任务（对应 language）
- 机器人本体（对应 proprioceptive state）

**多模态对齐**：`τ_v^4D = MLP(f_v^4D)`，`τ_p = MLP(f_p)`，指令走 tokenizer 得 `τ_l`，拼接后送 LLM + MLP action head：

```
[Δx, Δθ, Grip, Δt] = H(T([τ_v^4D, τ_p, τ_l]))    … 式(5)
```

**损失：L1 范数**（不是 OpenVLA 的交叉熵！）

```
L_action = Σ (|Δx-Δx̃|₁ + |Δθ-Δθ̃|₁ + |Grip-Grip̃|₁ + |Δt-Δt̃|₁)   … 式(6)
```

> **这是与 OpenVLA 的根本分歧**：OpenVLA 把动作离散化成 token 做分类（交叉熵）；VLA-4D 用 MLP head 直接回归连续值（L1）。复现时不能混。

## 3. 数据集

基于 **LIBERO** 改造，两方面扩展：

**输入模态**：在仿真里按固定采样频率重渲染人工设计轨迹，得到相机参数、**带时间戳的多视角视频**、深度、本体感知状态。

**动作标注**：**不改原有空间动作参数**，人工挑出"运动趋势一致"的 action chunk，按采样频率把其 step 数换算成可变的时间动作标注（即 Δt 的 ground truth）。

清洗筛选后：**40 个子任务，15 万条 vision-language-action 配对样本**。

## 4. 训练：两阶段

| 阶段 | 目标 | 数据 | 更新 | 冻结 | 超参 |
|---|---|---|---|---|---|
| **Stage 1**<br>4D 视觉-语言对齐 | 训 4D 视觉表征的推理能力，只用 LLM loss | Scan2Cap、ScanQA、ScanRefer、Multi3DRefer、Chat4D | cross-attention、时空嵌入、projector；**LLM 走 LoRA** | 视觉编码器、几何编码器、action head | lr 1e-4，bs 16 |
| **Stage 2**<br>机器人任务微调 | 训时空动作表征，用 L_action | 改造后的 LIBERO | action head、projector；**cross-attention 和 LLM 走 LoRA** | 其余全冻 | lr 5e-5，bs 24 |

**Backbone**：**Qwen2.5-VL-7B**（视觉编码器 + LLM 一体）+ **VGGT**（几何编码器）。Cross-attention 融合模块是 Transformer 结构。
**算力**：**8× RTX 6000 Ada**（即 8×48GB = 384GB 显存），优化器 AdamW。

### 5.2 消融（复现时最有参考价值的部分）

**Table 2 — 视觉表征模块**（LIBERO-Spatial / Goal）

| 空间嵌入 | 时间嵌入 | 特征融合 | Spatial | Goal |
|---|---|---|---|---|

> **关键观察：裸 backbone（全 × 那行）在 Spatial 上就有 89.4%，已经超过 OpenVLA 的 84.7%。**
> 也就是说 +13.2 的总增益里，约 4.7 来自 Qwen2.5-VL-7B 这个更强更新的底座，约 8.5 才来自 4D 机制本身。

**Table 3 — 动作表征**：只用空间参数 96.8 / 5.0s → 加时间参数 97.9 / **4.1s**
> 成功率只涨 1.1，**但完成时间从 5.0s 降到 4.1s**。作者结论：空间参数决定"能不能做成"，时间参数决定"做得快不快"。

**Table 4 — 输入模态**

| 视觉 | 4D线索 | 本体感知 | Spatial | Goal |
|---|---|---|---|---|
| 图像 | × | × | 85.9 | 88.0 |

| 视频 | √ | × | 97.1 | 97.3 |

> 单图→视频只涨 3.3；**4D 线索一加暴涨 7.9**；本体感知只是锦上添花（+0.8）。

**Table 5 — 时空编码**：无 96.3 → 有 97.9。理由：位置和时间**量纲尺度不同**，直接用会梯度冲突，专门编码能映射到统一特征空间、稳定收敛。
**Table 6 — 融合策略**：拼接 94.2 < 加权 95.8 < **注意力 97.9**

## 6. 局限（作者自陈）

真实环境部署仍有挑战，机械磨损、标定漂移等不可控因素会引入动作误差。未来计划引入强化学习做在线纠错。
