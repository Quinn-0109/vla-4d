> **一分钟版**（`docs/06` §0）：要保护的一句话是
> **「池化用的坐标系 ＝ 位置编码用的坐标系」**——这比"4D RoPE"本身重要，
> 因为 patch 级时空池化、度量 3D 表征、3D 坐标 RoPE 都各自有人做过，
> 没人把它们耦合在同一个度量 4D 坐标系里。
> 两个必须赢的对照：**G4 vs G3**（度量 4D vs 图像网格，**弱命题**）与
> **G4 vs M2**（一致 vs 错配，**强命题**，标题句的唯一直接证据）。
> 全部固定 token 预算 N=256，于是前提检验 **G2 vs G0** 也在同一预算上。
> **先跑零自由超参的最小版本**（§2.2 Phase 1），ToMe / λ 等一律压到 Phase 2。

|---|---|

## 几条踩过的坑（省得再踩一遍）

1. **新开终端/tmux 会掉回 base 环境**。踩过四次。把 `conda activate` 写进
   `~/.bashrc`；各启动脚本已加前置检查。
2. **相对路径要在仓库根目录跑**。`git` 会向上找 `.git`，相对路径不会——
   在子目录里 `git pull` 成功但 `bash scripts/xxx.sh` 找不到文件。
3. **依赖腐烂**。2023–2024 年的包大多没锁传递依赖上界，pip 会拉来 2026 年的
   版本导致运行时崩溃。全部锁在 `setup/constraints.txt`，每条都写了原因。
4. **`p > 0.05` 不等于「两者相同」**。本项目曾以 n=50 报出「压缩免费」，
   加量到 n=200 后被推翻。等价性声明必须先算功效。见 `docs/05` §7.5。
5. **就地修改的函数**。`normalize_gripper_action` 原地改并返回同一对象，
   不先复制会让"模型输出"和"执行动作"两个字段记成同一个值。
