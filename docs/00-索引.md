> **一分钟版**（`docs/06` §0）：要保护的一句话是
> **「池化用的坐标系 ＝ 位置编码用的坐标系」**——这比"4D RoPE"本身重要，
> 因为 patch 级时空池化、度量 3D 表征、3D 坐标 RoPE 都各自有人做过，
> 没人把它们耦合在同一个度量 4D 坐标系里。
> 两个必须赢的对照：**G4 vs G3**（度量 4D vs 图像网格，**弱命题**）与
> **G4 vs M2**（一致 vs 错配，**强命题**，标题句的唯一直接证据）。
> 全部固定 token 预算 N=256，于是前提检验 **G2 vs G0** 也在同一预算上。
> **先跑零自由超参的最小版本**（§2.2 Phase 1），ToMe / λ 等一律压到 Phase 2。

### token 消融

| 脚本 | 作用 |
|---|---|
| `src/pooling/token_select.py` | 五个压缩算子 + 两个诊断算子 + 位置修正。**可直接 `python` 跑自检** |
| `src/pooling/coord_pool.py` | **主线 Phase 1 池化算子**。G2/G3/G4/M2 共用这一份，差别只在传进去的 coords。`python src/pooling/coord_pool.py` 跑 7 项自检 |
| `src/pooling/rope4d.py` | **4D RoPE**（扩展式，不替换 1D 通路）。`python -m src.pooling.rope4d` 跑 6 项自检，含「q·k 只依赖坐标之差」的数值验证 |

| `src/analysis/collect_ablation.py` | 汇总；`--suite all` 做跨 suite 合并检验 |

### 微调（阶段 B 起）

| 脚本 | 作用 |
|---|---|
| `scripts/analyze_stride.py` | **定历史帧的采样间隔**。判据是「历史帧在多远之后就等同于同 episode 随便一帧」 |
| `scripts/depth_diag.py` | ⭐ **主线开跑前唯一能证伪核心创新的一步**。回放取仿真器深度，测「同一 (h,w) 在 K 帧内深度跳变」的**发生率**——低于 5% 说明 §1.2① 的错误合并机制不触发，G4 缺物理基础。顺带缓存 patch 级深度供 G4/M2 用 |
| `scripts/depth_bins.py` | ⭐ 上者的续算，**不重新渲染**。回答"跳变能不能被 G4 的 z 分箱分开"——诊断阈值 5 cm 与箱宽 ~30 cm 差六倍，发生率高不等于分得开 |
| `scripts/probe_vram.py` | 显存实测。`--sweep` 决策表，`--sweep_batch --K 8` 选 batch，**`--freeze_vision` 对齐实际训练配置**（不加就是错配置，见 `docs/05` §8.5），`--cameras 2` 双相机 |
| `src/common/lora.py` | LoRA 目标层选取。训练与显存实测**共用这一份**，防止两者配置不一致 |
| `scripts/prepare_finetune.sh` | `check` 体检 / `deps` 校正版本 / `data` 下数据集 |
| `scripts/finetune_single.py` | 单卡 LoRA 微调。`--bench_only True` 先测吞吐 |
| `scripts/merge_lora.py` | adapter 合并成可评测的完整 checkpoint |

## 几条踩过的坑（省得再踩一遍）

1. **新开终端/tmux 会掉回 base 环境**。踩过四次。把 `conda activate` 写进
   `~/.bashrc`；各启动脚本已加前置检查。
2. **相对路径要在仓库根目录跑**。`git` 会向上找 `.git`，相对路径不会——
   在子目录里 `git pull` 成功但 `bash scripts/xxx.sh` 找不到文件。
3. **依赖腐烂**。2023–2024 年的包大多没锁传递依赖上界，pip 会拉来 2026 年的
   版本导致运行时崩溃。全部锁在 `setup/constraints.txt`，每条都写了原因。
4. **`p > 0.05` 不等于「两者相同」**。本项目曾以 n=50 报出「压缩免费」，
   加量到 n=200 后被推翻。等价性声明必须先算功效。见 `docs/05` §7.5。
5. **⚠️ 子集不是满量的无偏估计**，哪怕它是满量的**严格**子集。
   评测确定性只保证子集**可复现**，不保证它**有代表性**。
   本项目用 `episode_idx < 5` 的 50 局判「硬门槛通过」（72.0% vs 76.0%, p=0.65），
   满量 500 局推翻：74.0% vs 84.2%，差 10.2 点、p=7.3e-05——
   那个子集恰好对官方 checkpoint 特别难，把真实差距掩盖了六个点。
   **n=50 已第三次误导本项目。判定一律用满量。** 见 `docs/05` §8.2。
6. **就地修改的函数**。`normalize_gripper_action` 原地改并返回同一对象，
   不先复制会让"模型输出"和"执行动作"两个字段记成同一个值。
